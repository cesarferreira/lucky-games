# Lucky Games

Four maths minigames: Bubble Pop, Dino Snacks, Rocket Race, and Memory Match.

[Play Lucky Games](https://cesarferreira.com/lucky-games/)

Choose any times tables from 1–12. Your selection is remembered in the same browser between visits. Bubble Pop, Rocket Race, and Memory Match practise multipliers through 12; Dino Snacks keeps groups small for counting.

## Run locally

Open `index.html` in a browser. No installation or build step is required.

## Publishing

GitHub Pages publishes the root of the `main` branch. Push changes to `index.html` to update the games.

## Checks

Run `node --test tests/games.test.cjs` (Node.js 18 or later).
