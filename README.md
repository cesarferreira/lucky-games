# Lucky Games

Four maths minigames: Bubble Pop, Dino Snacks, Rocket Race, and Memory Match.

[Play Lucky Games](https://cesarferreira.com/lucky-games/)

## Run locally

Open `index.html` in a browser. No installation or build step is required.

## Publishing

GitHub Pages publishes the root of the `main` branch. Push changes to `index.html` to update the games.
